# 📊 自选股智能监控系统

美股板块联动分析 + AI每日盘前简报 + 实时行情监控面板

## 🚀 快速部署

1. Fork 本仓库
2. Settings → Secrets → 添加 `GEMINI_API_KEY`、`RESEND_API_KEY`、`TO_EMAIL`
3. Settings → Pages → 启用 GitHub Pages（选择 gh-pages 分支）
4. Actions → Daily Stock Monitor → Run workflow 测试

## 🔧 配置说明

- **GEMINI_API_KEY**: [Google AI Studio](https://aistudio.google.com/app/apikey) 获取
- **RESEND_API_KEY**: [Resend.com](https://resend.com) 注册获取
- **TO_EMAIL**: 您的邮箱地址
